# Interaction map

| Surface | User action | Demo result |
|---|---|---|
| Faculty catalogue | Invoke a Faculty | Burns its PULSE cost and updates the balance and spent total |
| Edge Exchange | Adjust capacity slider | Recalculates simulated 20-minute PULSE settlement |
| Edge Exchange | Simulate lease | Adds PULSE to balance and earned total |
| Lattice | Toggle module | Connected: Faculties active and MCP available. Removed: Faculties dormant and MCP paused |
| Brain MCP | Switch Enterprise / Local | Changes endpoint description, connection mode and config snippet |
| Brain MCP | Connect / disconnect | Updates simulated connection state; never contacts a server |
| Brain MCP | Copy config | Copies the currently displayed example configuration |
| Navigation | Toggle mobile menu | Opens/closes the accessible mobile navigation |
